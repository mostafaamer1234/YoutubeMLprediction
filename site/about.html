An earlier single 80/20 split reported R² 0.54 for engagement. Cross-validation shows that was luck from a few outlier videos, so the claim was withdrawn.

Two data sources, one pipeline.

Collect

The YouTube Data API for trending and search results, and a Selenium scraper as a second source to compare against.

Featurize

Duration, title length and capitalization, keyword flags such as official or live, publish age and channel subscribers.

Model

Random forest and XGBoost regressors, with feature importance and a predict-the-mean baseline for every target.

Validate

Five-fold cross-validation. The scraped set has 10 rows, too few to judge, so it is reported but not claimed.
